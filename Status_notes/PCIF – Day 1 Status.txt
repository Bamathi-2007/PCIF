## Dependency List & Justification

### Backend Dependencies (`requirements.txt`)
- **`fastapi`**: Modern, fast web framework for building Python REST APIs with automatic OpenAPI `/docs` generation.
- **`uvicorn[standard]`**: High-performance ASGI web server to run the FastAPI application.
- **`pydantic`**: Data validation and setting management using Python type annotations.
- **`python-dotenv`**: Reads key-value pairs from a `.env` file and sets them as environment variables.
- **`pymongo`**: Standard MongoDB driver required for data persistence in Days 9–11.

### Frontend Dependencies (`frontend/package.json`)
- **`react` & `react-dom`**: UI library for component-based interface rendering.
- **`vite`**: Lightning-fast frontend build tool and development server.
- **`lucide-react`**: Clean, lightweight SVG icon package for modern dashboard UI elements.

## How to Run the Project

### 1. Running the Backend Server
From the project root directory:
```bash
py -m uvicorn backend.main:app --reload
```
- Server URL: `http://localhost:8000`
- Interactive API Documentation (Swagger): `http://localhost:8000/docs`

### 2. Running the Frontend Server
From the `frontend/` directory:
```bash
cd frontend
npm run dev
```
- Local Web UI: `http://localhost:5173`
